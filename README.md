# Ferns & Petals Sales Analysis Dashboard

## Project Overview
Designed and developed an interactive Excel dashboard to analyze sales performance, customer behavior, delivery efficiency, and product trends for Ferns & Petals using business analytics and data visualization techniques.

The dashboard enables dynamic filtering and insight generation across occasions, products, order timelines, and customer purchasing patterns.

---

## Tools & Techniques Used
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Slicers and Interactive Filters
- KPI Cards
- Conditional Formatting
- Data Cleaning & Transformation
- Dashboard Design
- Data Visualization

---

## Key Features
- Revenue and Order KPI Tracking
- Customer Spending Analysis
- Delivery Performance Monitoring
- Occasion-wise Revenue Analysis
- Product Performance Insights
- Monthly Revenue Trends
- Top Cities by Orders
- Interactive Filtering using Slicers
